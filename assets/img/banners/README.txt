Collection banners

The collection cards show only these images (no text on top), so put
any wording you want straight into the banner picture itself.

  men.jpg    - Men's Collection
  women.jpg  - Women's Collection
  best.jpg   - Best Sellers
  new.jpg    - New Arrivals (shown on mobile only)

Desktop shows them as wide cards (about 2.2 : 1), phones as square
tiles, so keep the important part in the centre.
Recommended size: 1200 x 1200 px, JPG under ~250 KB.

A card with no file shows the plain colour + watch icon instead.
